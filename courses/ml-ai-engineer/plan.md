# ML & AI Engineer — оқу картасы

Материал тілі: негізінен ағылшынша. Уақыт шамамен. Материалдар осы сессияда ресми беттерден расталған.

## 1-кезең. Негіз: Python және математика (шамамен 3 ай)

- 1. CS50P — Harvard CS50's Introduction to Programming with Python, David Malan, ағылшынша, тегін (cs50.harvard.edu/python). Нөлден Python: есептер мен тесттері бар. 10 апта, аптасына 3–9 сағат. Python-ды жақсы білсең, өткізіп жібер.
- 2. Essence of linear algebra — 3Blue1Brown, ағылшынша, тегін YouTube, 15 қысқа бейне (3blue1brown.com/topics/linear-algebra). Вектор мен матрицаның геометриялық мағынасы; бірнеше күнде көріп шығасың.
  - түсінбесең: besminut-teacher: векторлар мен матрицалар ML үшін
- 3. Mathematics for Machine Learning — Deisenroth, Faisal, Ong (Cambridge UP, 2020), ағылшынша, PDF тегін (mml-book.com). Бастан аяқ оқымайсың: 1-кезең бойы анықтамалық ретінде ал. Керек бөлімдері: сызықтық алгебра, векторлық есептеу, ықтималдық және үлестірімдер, оңтайландыру.
  - түсінбесең: besminut-teacher: градиент пен градиенттік түсу

Дайын болу критерийі:
- [ ] Python-да 100–200 жолдық жобаны өзің жаздың, тест бар
- [ ] Матрицаны векторға көбейтудің геометриялық мағынасын сызып түсіндіре аласың
- [ ] Градиент, ықтималдық үлестірімі дегенді өз сөзіңмен айта аласың

**Жоба (өз брифім): NumPy-мен сызықтық регрессияны градиенттік түсу арқылы нөлден жаз. Мақсаты: математиканы кодпен байланыстыру. Қадамдары: 1) жасанды дерек жаса, 2) жоғалту функциясын жаз, 3) градиентті қолмен есепте, 4) циклмен үйрет, 5) қателік графигін сал. Дайын: README мен графигі бар репозиторий.**

## 2-кезең. Классикалық ML (шамамен 3 ай)

- 4. Kaggle Learn — микрокурстар Pandas, Intro to Machine Learning, Intermediate Machine Learning, ағылшынша, тегін, браузерде (kaggle.com/learn). Әрқайсысы шамамен 3–4 сағат: деректермен жұмыс, алғашқы модельдер, валидация, жетіспейтін мәндер.
- 5. Machine Learning Specialization — Andrew Ng, DeepLearning.AI және Stanford Online, 3 курс, ағылшынша (deeplearning.ai/courses/machine-learning-specialization, Coursera-да да бар). Нұсқаулы және бақыланбайтын оқыту, нейрондық желілер, шешім ағаштары. 2 ай, аптасына 10 сағат. Сертификат ақылы, қолжетімділік шартын сайттан тексер.
  - түсінбесең: besminut-teacher: шамадан тыс үйрену (overfitting) және валидация

Дайын болу критерийі:
- [ ] Pandas-пен таза емес деректі тазалай аласың
- [ ] Модельді оқу және тест жиынына бөліп, метриканы дұрыс таңдай аласың
- [ ] Шешім ағашы, сызықтық және логистикалық регрессияның айырмасын мысалмен түсіндіре аласың

**Жоба 1 (бар жоба): Kaggle Intro to ML курсының соңғы жаттығуы — нақты Kaggle жарысына қатысу. Жоба 2 (өз брифім): кестелік деректе толық ML жобасы. Қадамдары: 1) ашық датасет ал (Kaggle), 2) деректі зертте, 3) 2–3 модельді валидациямен салыстыр, 4) қателік талдауы жаз. Дайын: ноутбук пен README (мәселе, метрика, нәтиже, қорытынды).**

## 3-кезең. Терең оқыту (deep learning) (шамамен 2–3 ай)

- 6. Neural networks — 3Blue1Brown, 4 бейне, шамамен 1 сағат, ағылшынша, тегін (3blue1brown.com/topics/neural-networks). Нейрондық желі, градиенттік түсу, backpropagation интуициясы.
  - түсінбесең: besminut-teacher: backpropagation
- 7. Practical Deep Learning for Coders — fast.ai, Jeremy Howard, 2022 нұсқасы, 9 сабақ, әрқайсысы шамамен 90 минут, ағылшынша, тегін (course.fast.ai). Алдымен практика: үлгіні жұмыс істетесің, кейін ішіне үңілесің. Ішінде deployment да бар.
- 8. Neural Networks: Zero to Hero — Andrej Karpathy, ағылшынша, тегін YouTube, 9 лекция, шамамен 20–30 сағат (karpathy.ai/zero-to-hero.html). Backpropagation-нан GPT-ге дейін нөлден кодпен жазасың. Алдыңғы қадамның практикасынан кейін келсе, жақсы ұғылады.
  - түсінбесең: besminut-teacher: attention және transformer

Дайын болу критерийі:
- [ ] PyTorch-та кескін немесе мәтін модельін өзің үйреттің
- [ ] Backpropagation-ды қағазда кіші желіде есептей аласың
- [ ] Кішкентай GPT тәрізді тілдік модельді өзің жазып, оқыттың

**Жоба 1 (бар жоба): fast.ai сабағындағы deployment тәжірибесі: өз кескін классификаторыңды веб-демо ретінде жарияла. Жоба 2 (Karpathy): әр лекциядағы код пен соңындағы жаттығуларды өзің қайта жаз, көшірмей. Дайын: жарияланған демо және GitHub репозиторийі.**

## 4-кезең. LLM және AI-инженерия (шамамен 2–3 ай)

- 9. LLM Course — Hugging Face, ағылшынша, тегін (huggingface.co/learn/llm-course). Transformers, Datasets, Tokenizers кітапханалары, классикалық NLP тапсырмалары, демо жасау, LLM-ді fine-tuning және reasoning модельдері.
  - түсінбесең: besminut-teacher: fine-tuning және tokenizer
- 10. AI Agents Course — Hugging Face, ағылшынша, тегін (huggingface.co/learn/agents-course). Агент деген не, smolagents, LlamaIndex, LangGraph; соңында бенчмаркке арналған финал тапсырмасы.
- 11. AI Engineering — Chip Huyen, O'Reilly, 2025, ағылшынша, ақылы кітап (huyenchip.com/books). Foundation model негізіндегі қосымшаны жобалау, бағалау, дерек. Алдыңғы екі материалдан кейін оқы, сонда бәрін жүйелейді.
  - түсінбесең: besminut-teacher: LLM қосымшасын бағалау (evaluation)

Дайын болу критерийі:
- [ ] Дайын LLM-ді өз деректеріңе fine-tuning немесе retrieval арқылы бейімдей аласың
- [ ] Агентке құрал (tool) қосып, жұмыс істеттің
- [ ] LLM қосымшасының сапасын өлшейтін өз тестіңді жаздың

**Жоба 1 (бар жоба): Agents Course финал тапсырмасы: бенчмаркте 30% немесе одан жоғары балл жинау. Жоба 2 (өз брифім): өз құжаттарың бойынша сұраққа жауап беретін RAG көмекшісі. Қадамдары: 1) құжат жина, 2) бөлшектеп индекстеу, 3) сұрақ-жауап, 4) 20 сұрақтан тұратын бағалау жиыны, 5) нәтижені салыстыру. Дайын: демо, README, бағалау нәтижесі. Қосымша, тереңдету үшін (міндетті емес): Stanford CS224N (NLP with Deep Learning), YouTube-тағы тегін лекциялар.**

## 5-кезең. Өндіріс: MLOps (шамамен 1–2 ай)

- 12. MLOps Course — Made With ML, Goku Mohandas, ағылшынша, тегін, 49 сабақ, ашық код (madewithml.com). Эксперименттен өндіріске: дизайн, әзірлеу, деплой, итерация; тест, CI/CD, қайта жаңғыртымдылық, мониторинг.
  - түсінбесең: besminut-teacher: MLOps, модельді өндіріске шығару

Дайын болу критерийі:
- [ ] Модельің API арқылы жұмыс істеп тұр
- [ ] Кодта тесттер мен қайта жаңғыртылатын орта бар
- [ ] Жобаны өзгеріссіз басқа адам іске қоса алады (README бойынша)

**Қорытынды жоба (өз брифім): 2-4 кезеңдегі жобаның бірін өндіріске дайындау: API, тесттер, Docker, мониторинг, README. Дайын: репозиторий мен жұмыс істейтін демо; портфолиоға салуға жарайды.**

Ескерту: уақыт шамамен; ол сенің ыңғайлы қарқыныңа байланысты. Материал атаулары мен мазмұны осы сессияда ресми беттерден расталған. Сертификат, баға және қолжетімділік шарттары өзгеруі мүмкін, сайттан тексер.
